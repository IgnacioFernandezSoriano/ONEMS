Rôles et accès

Ce que chaque personne voit et peut faire dans ONEMS dépend de ses rôles dans le compte de son pays. Cette page explique les rôles, les droits et comment l’Account Manager et l’UPU account manager les gèrent.

Les six rôles

Un rôle est la fonction d’une personne dans le compte de son pays. Chaque rôle donne des droits : quelles options du menu la personne voit et où elle peut modifier des données. Il y a toujours ces six rôles, dans tous les comptes.

RôleCe qu’il fait
Account ManagerResponsable du compte. Gère presque tout et décide des accès de son équipe.
Allocation Plan ManagerPrépare et ajuste les plans d’envois : générateur, équilibrage et plans d’allocation.
Panelist ManagerGère les panélistes, leurs incidents et leur disponibilité.
Materials SupplierGère les matériaux : besoins, stock et catalogue.
DO coordinatorCoordonne la partie RFID : centres postaux, lecteurs et SLA de segment.
UPU account managerPersonne de l’UPU qui suit le compte. A des droits étendus et décide aussi des accès.
Les noms des rôles s’affichent en anglais dans toutes les langues, comme dans ONEMS.

Edit, View et sans accès

Pour chaque option du menu, un rôle a l’un de ces trois droits :

Edit

Voit l’écran et peut modifier des données : créer, enregistrer, supprimer ou importer.

View

Voit l’écran mais ne peut rien modifier. Les boutons créer, enregistrer et supprimer sont masqués et l’écran affiche la marque Consultation uniquement.

—

L’option n’apparaît pas dans le menu.

Plusieurs rôles s’additionnent

Une personne peut avoir plusieurs rôles. Pour chaque option, le droit le plus élevé l’emporte : Edit avant View, et View avant rien.

Exemple : dans le modèle, le Panelist Manager a View sur Gestion des stocks et le Materials Supplier a Edit. Une personne qui a les deux rôles a Edit.

Utilisateurs sans rôle

Un utilisateur du compte sans aucun rôle voit seulement les rapports et le Centre d’aide, en View :

  • Équité territoriale
  • Conformité
  • Analyse des Routes
  • Analyse des segments
  • Centre d'aide

Il ne voit pas le Tableau de bord. À la connexion, ONEMS ouvre le premier de ces écrans.

Cette liste est la même dans tous les comptes et ne peut pas être modifiée. Si quelqu’un a besoin de plus, il faut lui donner un rôle.

Rôles dans plusieurs comptes

Une personne peut avoir des rôles dans plusieurs pays ; par exemple, un UPU account manager qui suit plusieurs comptes. Dans ce cas, le sélecteur Compte apparaît en haut du menu.

  1. Choisissez le compte dans le sélecteur Compte.
  2. La page se recharge toute seule.
  3. Vous voyez maintenant les menus, les droits et les données de ce compte.
On travaille avec un seul compte à la fois. Si ONEMS est ouvert dans deux onglets du navigateur, les deux partagent le même compte : après un changement dans l’un, rechargez l’autre.

Demander un changement d’accès

S’il vous manque une option du menu, ou si vous avez besoin d’Edit là où vous n’avez que View, demandez-le à l’Account Manager ou à l’UPU account manager de votre compte. Eux seuls peuvent modifier les rôles et les droits du compte.

Ensuite : le changement est enregistré immédiatement. Rechargez la page pour voir votre menu mis à jour.

L’onglet Rôles et accès

Cette partie concerne l’Account Manager et l’UPU account manager : ce sont les seules personnes du compte qui peuvent modifier ses accès. Cette autorisation est fixe : elle ne peut pas être retirée depuis la matrice des droits.

Où le trouver

  • Dans le menu Administration › Rôles et accès. Seuls l’Account Manager et l’UPU account manager le voient. Il ouvre l’onglet du compte sur lequel vous travaillez.
  • Le superadmin de l’UPU l’a aussi dans le formulaire de chaque compte, dans l’onglet Rôles et accès, à côté de Général.

Contacts du compte

Ce sont six e-mails, un par rôle. ONEMS y envoie les avis et e-mails automatiques du compte, comme le rapport d’opération.

Un contact n’est pas un rôle. Mettre un e-mail dans les contacts ne donne pas accès à ONEMS. Et avoir un rôle ne fait pas recevoir les avis : seul l’e-mail inscrit dans les contacts les reçoit.
  1. Saisissez l’e-mail de chaque rôle. Laissez-le vide si ce rôle n’existe pas dans votre compte.
  2. Cliquez sur Enregistrer les contacts.
Ensuite : Enregistré s’affiche et les prochains avis partent vers les nouveaux e-mails. Le changement figure dans Dernières modifications.

Rapport d'opération

L’e-mail « ONE operations report » part vers les contacts du compte ; l’Account Manager et l’UPU account manager sont en copie. Chaque compte a son propre calendrier : certains jours de la semaine, un jour par mois ou jamais. Le superadmin de l’UPU le règle dans l’onglet Général du compte. Pour le changer, demandez-le à votre UPU account manager.

Changer un droit

Le tableau Droits de chaque rôle a une ligne par option du menu, groupées comme dans le menu, et une colonne par rôle.

  1. Trouvez la ligne de l’option du menu.
  2. Dans la colonne du rôle, ouvrez le sélecteur et choisissez Edit, View ou —.
  3. Il n’y a pas de bouton d’enregistrement : le changement est enregistré immédiatement.
Ensuite : toutes les personnes qui ont ce rôle dans ce compte ont le nouveau droit. Elles le verront en rechargeant la page. Les autres comptes ne changent pas.
La colonne Sans rôle est fixe : elle est la même dans tous les comptes et ne peut pas être modifiée.

Rôles des utilisateurs

Le tableau Utilisateurs et leurs rôles affiche les utilisateurs du compte, avec une case par rôle. Un utilisateur peut avoir plusieurs rôles.

  1. Trouvez l’utilisateur.
  2. Cochez la case du rôle pour le lui donner, ou décochez-la pour le lui retirer.
  3. Le changement est enregistré immédiatement.

Rôles « Provisoire »

À la mise en place des rôles, ONEMS en a attribué certains automatiquement. Ils portent la marque Provisoire et une case orange. Vérifiez-les :

  • Si le rôle est correct, confirmez-le : décochez la case puis cochez-la de nouveau. La marque disparaît.
  • S’il n’est pas correct, décochez-le et cochez le bon rôle.
Vous ne pouvez pas retirer votre propre dernier rôle de gestion. Si c’est votre seul rôle d’Account Manager ou d’UPU account manager dans le compte, ONEMS ne vous laisse pas le retirer, pour que personne ne perde la possibilité de corriger cet onglet. Donc, si votre propre rôle de gestion est Provisoire, demandez à un autre responsable ou au superadmin de le confirmer.

Ajouter un utilisateur existant par e-mail est réservé au superadmin. Cela sert à donner un rôle dans votre compte à une personne qui est déjà utilisateur d’un autre compte. Demandez-le à l’UPU.

Ensuite : l’utilisateur a ses nouveaux droits en rechargeant la page. Le changement figure dans Dernières modifications.

Revenir au modèle

Chaque compte part du modèle de droits et peut l’ajuster. Le bouton Revenir au modèle annule toutes les modifications de la matrice de votre compte.

  1. Cliquez sur Revenir au modèle.
  2. ONEMS demande une confirmation. Acceptez.
Ensuite : tous les droits du compte reviennent au modèle. Les rôles des utilisateurs et les contacts ne changent pas.

Dernières modifications

La liste Dernières modifications affiche les changements faits dans l’onglet : Date, Qui l’a fait et la Modification ; par exemple, Panelist Manager · Panélistes : View → Edit. Les changements automatiques apparaissent comme Système.

Créer des utilisateurs avec rôles

Les personnes qui ont Edit sur Utilisateurs peuvent créer des utilisateurs. Dans le modèle : l’Account Manager et l’UPU account manager.

  1. Ouvrez Administration › Utilisateurs.
  2. Cliquez sur Créer un utilisateur.
  3. Remplissez les données de l’utilisateur : E-mail, Mot de passe, Nom complet…
  4. Dans Rôles dans le compte (facultatif), cochez ses rôles.
  5. Cliquez sur Créer.
Ensuite : l’utilisateur apparaît dans Utilisateurs et leurs rôles avec ces rôles. Sans aucun rôle coché, il ne voit que les rapports (voir Utilisateurs sans rôle).
Seuls l’Account Manager et l’UPU account manager voient les cases des rôles. Si une autre personne crée l’utilisateur, il faut ensuite lui donner ses rôles dans l’onglet.

Questions

Un écran affiche « Consultation uniquement ». Pourquoi ?
Vos rôles ne vous donnent que View sur cette option. Si vous devez modifier des données, demandez Edit à l’Account Manager ou à l’UPU account manager de votre compte.
Il me manque une option dans le menu.
Aucun de vos rôles n’y a accès. Demandez-la à l’Account Manager ou à l’UPU account manager. Si vous avez plusieurs comptes, vérifiez dans le sélecteur Compte que vous êtes dans le bon.
J’ai le rôle, mais je ne reçois pas les avis automatiques.
Les avis partent vers les e-mails de Contacts du compte, pas vers les utilisateurs qui ont le rôle. Demandez qu’on ajoute votre e-mail aux contacts.
Un changement dans mon compte touche-t-il d’autres pays ?
Non. Chaque compte a ses propres droits, contacts et rôles.
Puis-je créer un nouveau rôle ou en renommer un ?
Non. Les six rôles sont les mêmes dans tous les comptes. Ce que chaque compte ajuste, ce sont ses droits.
